Implement the work described by the user in the spec or tickets.

Use the `tdd` skill where possible, at pre-agreed seams.

Run typechecking regularly, single test files regularly, and the full test suite once at the end.

Once done, use the `code-review` skill to review the work.

Report the final diff, verification results, current branch, and worktree state. Commit only when the user has explicitly authorized a commit for this task; otherwise leave the verified changes uncommitted and provide the exact proposed commit message.
